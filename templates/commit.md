### v1
```
<type>: <message>
<body>
branch: <branch>
session_id: <CLAUDE_SESSION_ID>
datetime: <datetime>
```

`type`: follows Conventional Commits standards
`body`: list of changes implemented - optional
`branch`: the respective branch where that commit was submitted
`CLAUDE_SESSION_ID`: the current session id when the commit was written
`body`: list of changes implemented - optional
`datetime`: when the commit was written
